# Pravda Skill Atlas

**王裕硕的 AI 技能与工作流目录**

这里汇总我创建和维护的 AI 助手技能。你可以从这个目录找到适合任务的项目，再进入对应仓库查看使用说明、示例和更新记录。

## Agent 管理入口

创建或维护我的技能前，请先阅读 [AGENTS.md](AGENTS.md)，了解总目录与独立技能仓库的分工、文件组织、验证和同步流程，以及公开状态与写入授权要求。

## 技能目录

目录已建立，首批技能项目整理中；目前尚未收录已发布的技能仓库。

后续项目将按下面的信息展示：

| 信息 | 内容 |
| --- | --- |
| 项目名称 | 链接到独立的技能仓库 |
| 任务用途 | 说明这组技能能够帮助完成什么 |
| 适用工具 | 标明已经验证的 AI 工具与运行环境 |
| 使用入口 | 链接到安装说明、使用示例或具体技能 |
| 维护状态 | 标明实验中、可用或已归档 |

## 如何使用

选择需要的项目，进入其仓库，先查看适用工具与运行条件，再按照项目说明安装或使用。具体依赖、权限要求和操作步骤由各项目说明。

## 仓库组织

本仓库作为统一入口，维护项目介绍和导航。每个独立项目可以包含一项技能，也可以维护一组相关技能；技能文件、脚本、模板和示例保存在对应项目仓库。

各项目分别维护自己的版本、使用说明与问题反馈。更新项目后，同步修改本目录中受影响的介绍和链接。

## 更新与反馈

- 具体技能的使用问题和改进建议：提交到对应项目的 Issues。
- 本目录的链接、介绍或分类问题：提交到本仓库的 Issues。
